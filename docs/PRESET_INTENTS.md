# 常用意图模板

> 供联调时粘贴到 TARS 对话页。输入后点击“发送”。模板只是自然语言任务，仍受 Agent schema、
> 动作白名单、用户授权应用目录和敏感确认保护。

## 固定技能与启动授权

```text
open settings
```

验证固定技能和已授权的 `launch`。系统设置必须已在“允许启动的应用”中勾选；固定技能同样不能
绕过应用目录。

```text
open gmail
```

验证 Gmail 的受限启动。设备未安装或未在设置页勾选 Gmail 时，应被安全拒绝。

## 表单输入基线

```text
打开联系人，新增联系人，名字填 Zhang San，电话填 13800138000，最后保存。
```

用于验证跨应用启动、表单聚焦和文本输入。最后“保存”属于敏感语义时，应确认前台浮层出现且取消
后任务停止。

## Gmail 发信诊断

```text
打开 Gmail，撰写邮件给 violetylove@163.com，主题 test subject，正文 hello，然后发送。
```

Gmail 的联系人建议卡与输入法可能挤压主题/正文区域，属于应用特有布局，不能作为通用表单的通过
标准。需定位时请在设置页上传 Android 日志，并以同一 session ID 对照 Agent 审计日志。

## 录入提示

- AVD 上通过 `adb input text` 写入长文本或中文可能丢字；优先使用对话输入框粘贴，或分段输入。
- 可替换示例中的联系人、地址、主题和正文；避免在截图、日志或提交中保留真实敏感内容。
